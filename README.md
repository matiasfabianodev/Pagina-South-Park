# Página South Park 

Proyecto web desarrollado con **HTML y CSS** como trabajo académico. Consiste en una página informativa sobre la serie *South Park*, con información sobre sus creadores, una sinopsis y una descripción de sus personajes.

## Tecnologías utilizadas
- HTML5
- CSS3

## Características
- Diseño adaptable a dispositivos móviles y tablets (responsive design).
- Secciones informativas sobre la serie y sus personajes.
- Formulario de contacto visual, sin funcionalidad implementada.

## Origen del proyecto
Este proyecto fue desarrollado originalmente y publicado en otra cuenta de GitHub, asociada a mi institución educativa. Posteriormente, fue incorporado a mi cuenta personal como parte de mi portfolio de proyectos.
